Third-year computer engineering student at **TVZ (Zagreb)**, delivering React and TypeScript applications since 2021.

Earlier this year I was the **sole active QA engineer** on a mobile application at **Porsche eBike Performance**, across iOS and Android, in an international team with a release process where every build is verified before it reaches users. I wrote Appium automation for regression flows and tested gRPC and HTTP endpoints against the application contract rather than only through the interface. Testing, reproducing a defect properly and reading someone else's code carefully are habits now rather than things I still need to learn.

**I am looking for a development role in a team where someone more experienced reviews my code.** Graduating June 2027, available immediately.

### What I am working on

- **[Vectra XR](https://vectraxr.com)**, co-founder and developer. A 3D product configurator for things that are built to order, from custom gym rigs to prefab homes. Turborepo monorepo, Next.js App Router, Prisma with PostgreSQL, Clerk for auth, and a Python service that converts 3D files with caching keyed on the source hash.
- **Freelance since 2021.** Client applications end to end: scoping, build, testing, deployment and maintenance. [Stolarija-BM](https://github.com/Brkic365/Stolarija-BM) is a catalogue, web shop and the admin dashboard a furniture workshop runs on.
- **[Pentix](https://pentix.eu)**, live. Counts push-up reps from a phone camera using MediaPipe PoseLandmarker over WASM, so the video never leaves the device.
- Smaller things that answer a question I had: [Shelf](https://cocktailshelf.vercel.app) works out what you can pour from the bottles you own and which one bottle would unlock the most, and [Tavola](https://github.com/Brkic365/tavola) shows a dish at true size in AR before you order it.
